# Feris-Teach is built for its owner alone

Feris-Teach is built for one person, its owner. It is theirs on any machine they run it on, Linux or Windows, starting from a fresh clone on a clean machine. The repo is public on GitHub, but nothing in it is made for anyone else: the docs speak to the owner and the agents that build Feris-Teach for them, and the voice runs on Qwen, on an NVIDIA GPU.

## Considered Options

- **An open-source product for anyone who clones it**, with a voice that runs on any CPU: rejected. It held the voice back to what a CPU can do, and wrote the docs for visitors and contributors.

## Consequences

- The voice needs an NVIDIA GPU; the README states the minimum, and below it there is no voice.
- The docs speak to the owner and their agents, never to visitors or contributors.
