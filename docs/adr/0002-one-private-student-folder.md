# Everything personal lives in one git-ignored student folder

The repo is public and is meant to be cloned and run as-is, so it ships only the product: the agent (skills, subagents, hooks), the classroom, the tools, the docs and one small sample book written for this repo. Everything that belongs to a student (profile, their books and progress, sources, inbox) lives in a single git-ignored folder, so nothing personal can be committed by accident.

Sources are the student's responsibility: the repo never contains third-party books, images or documents, only the sample book's original content.
