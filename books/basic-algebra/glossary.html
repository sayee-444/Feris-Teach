Basic algebra

Glossary

The words of the book, in alphabetical order.

Coefficient
The number that multiplies a variable in a term. In 7n the coefficient is 7.
Constant
A term with no variable, whose value never changes. In 3x + 5 the constant is 5.
Equation
A statement that two expressions are equal, written with an equals sign: 2x + 3 = 11.
Evaluate
To work out the value of an expression by putting a number in place of each variable.
Expression
Numbers and variables joined by operations, with no equals sign: 3x + 5.
Intercept
The value of y where a line crosses the y-axis, that is, when x = 0. In y = mx + b it is b.
Like terms
Terms with exactly the same variable part, such as 4x and 2x. They can be combined into one.
Linear
Describes an equation whose graph is a straight line, such as y = 2x + 1. No variable is squared or multiplied by another.
Slope
How much y changes when x goes up by 1; the steepness of a line. In y = mx + b it is m.
Solution
A value of the variable that makes an equation true. The solution of 2x + 3 = 11 is x = 4.
Term
One of the parts of an expression joined by + or −. 3x + 5 has the terms 3x and 5.
Variable
A letter that stands for a number that is unknown or can change.
