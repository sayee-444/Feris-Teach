Basic algebra · Lesson 2.1

Solving a linear equation

By the end you can find the number that makes an equation like 2x + 3 = 11 true, and check that it does.

1.An equation is a balance

An equation says that two expressions are equal: 2x + 3 = 11. A solution is a value of the variable that makes the statement true. Here x = 4 works, because 2 × 4 + 3 = 11.

Picture a balance with 2x + 3 on the left pan and 11 on the right. It is level. Whatever you do to one pan, do the same to the other, and it stays level.

2.Undo, step by step

To solve, undo what was done to x, in reverse order, doing each step to both sides. In 2x + 3, x was multiplied by 2 and then 3 was added. So first take away 3, then divide by 2:

  1. Start: 2x + 3 = 11
  2. Subtract 3 from both sides: 2x = 8
  3. Divide both sides by 2: x = 4

Finally, check by putting the solution back into the original equation: 2 × 4 + 3 = 11. Both sides agree, so x = 4 is the solution.

Variables on both sides? First move every x term to one side, by subtracting the same term from both sides. In 5x − 4 = 2x + 8, subtract 2x to get 3x − 4 = 8, and carry on as before.

3.Check yourself

Solve 3x − 5 = 13. What is x?

Add 5 to both sides: 3x = 18. Divide by 3: x = 6. Check: 3 × 6 − 5 = 13.

To solve x / 4 + 1 = 3, what is the first step?

The 1 was added last, so it is undone first: x / 4 = 2. Then multiply by 4: x = 8.

Solve 5x − 4 = 2x + 8. What is x?

Subtract 2x: 3x − 4 = 8. Add 4: 3x = 12. Divide by 3: x = 4. Check: both sides are 16.
